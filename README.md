# AI Career Coach

AI Career Coach is an AI-powered platform that helps job seekers analyze resumes, identify skill gaps, generate interview questions, and create personalized learning roadmaps.

## Features

### Resume Analysis

Upload a resume and extract key skills and experience.

### Job Description Matching

Compare resumes against job descriptions.

### Skill Gap Detection

Identify missing skills required for target positions.

### Interview Preparation

Generate personalized interview questions.
